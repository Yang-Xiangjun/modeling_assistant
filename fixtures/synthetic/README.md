# Synthetic PCBA fixtures

The `pcba/` set is generated by `tools/make_synthetic.py` and is intended for
contract, geometry, and drawing pipeline tests while native NX fixtures are
being recorded.  `reference/` contains a raw model and its matching raw
drawing.  The three sibling models vary the board size, mounting-hole
locations, or connector count.  Every generated JSON file carries
`"synthetic": true` (raw model and drawing files carry it in `source`).

Regenerate with `make synthetic`.  `uv run python tools/make_synthetic.py
--check` verifies that committed JSON is byte-identical to a fresh generation.
